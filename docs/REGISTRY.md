# Реестр

Реестр раздаёт `.yampkg` и подписанные JSON-индексы. YAM только читает его:
публикации в этом репозитории нет.

```sh
yam registry add official https://registry.example/v2 --key ed25519:...
yam search spotify
yam info author/player
yam plan author/player
yam install author/player
```

Пакет имеет имя `<пространство>/<имя>`. Правило для операторов реестра:
не перепубликовывать одну комбинацию имени, версии и платформы — YAM это не
проверяет, он лишь сверяет скачанный архив с размером и SHA-256 из индекса.

Перед установкой YAM проверяет подпись индекса, размер и SHA-256 каждого
архива, затем устанавливает зависимости раньше запрошенного пакета.

Индексы публикуются вместе с отсоединённой подписью:

```text
/v2/index.json
/v2/index.json.sig
/v2/packages/<пространство>/<имя>/index.json
/v2/packages/<пространство>/<имя>/index.json.sig
```

Подпись — Base64 Ed25519 над точными байтами JSON. Ключ в настройках имеет вид
`ed25519:<base64-публичный-ключ>`.

Entware в реестр не загружается: пакет может только объявить нужные пакеты
`opkg`.

## Короткие имена

`yam install spotify` (без `/`) резолвится так:

1. Уже установленный пакет `yam/spotify`, либо любой установленный пакет,
   предоставляющий `spotify` через `provides`, закрывает зависимость — ничего
   не ставится.
2. Иначе кандидаты — пакет `yam/spotify`, если он есть в реестре, и каждый
   пакет из `yam/`, у которого `spotify` указан в `provides` записи каталога.
   Ровно один кандидат — выбирается автоматически.
3. Несколько кандидатов в `yam/` — ошибка со списком, ничего не выбирается.
4. Нет кандидатов в `yam/`, но есть вне его — ошибка с подсказкой поставить
   нужный пакет явно по полному имени `<namespace>/<name>`.

Полное имя `<namespace>/<name>` всегда резолвится ровно в этот пакет.
`recommends` при установке из реестра пока не ставятся.

## Формат индекса

`/v2/index.json` — каталог: `format` (число), `packages[]`. Запись каталога:
`name`, `summary`, `latest` — обязательные; `targets`, `keywords`, `provides`
— списки (по умолчанию пустые); `homepage` — строка или `null`. `provides`
показывает, какие виртуальные имена предоставляет последняя версия; по нему
ищутся кандидаты для коротких имён без загрузки индексов всех пакетов.
Старые индексы без `provides` читаются как пустой список.

`/v2/packages/<пространство>/<имя>/index.json` — индекс пакета: `format`
(должен быть `2`), `name` (должен совпасть с запрошенным), `versions` —
таблица «версия → метаданные». Метаданные версии: `artifacts` (таблица
«ID платформы или `any` → артефакт»), `published_at` (строка или `null`),
списки `depends`, `recommends`, `provides`, `conflicts`, `replaces`
(по умолчанию пустые). `replaces` зеркалит `MANIFEST.yaml`; резолвер его пока
не использует.

Артефакт: `arch` (должен совпасть с `arch` профиля), `url`, `sha256`, `size`.
Для платформы берётся артефакт с её ID, иначе артефакт `any`.
